# v2.23.11

Исправление OTA-обновления при ошибке «путь не найден».

- Обновлятор больше не зависит от PATH для запуска PowerShell.
- PowerShell ищется по прямому системному пути Windows и через PATH как резервный вариант.
- Перед запуском updater проверяет существование текущего EXE, скачанного EXE и папки программы.
- Все служебные каталоги updates/previous и каталог лога создаются заранее.
- Updater запускается с рабочей папкой update_root.
- При ошибке теперь показываются конкретные пути: PowerShell, скрипт обновления, текущий EXE и новый EXE.
- Сохранён автоматический откат на предыдущий EXE, если новая версия сразу завершается.
- Полный регресс 2.17.2–2.23.11, Windows build и smoke-test пройдены.

UX-релиз по итогам экспертного исследования.

- «Следующее действие» в карточке разделено на информацию о сроке и короткую основную кнопку.
- На главном экране три быстрых статуса заменены одной контекстной кнопкой следующего действия; старые команды сохранены в контекстном меню строки.
- В основной таблице «Площадка», «Заказчик» и «Товары / Кол-во» выровнены по левому краю для более быстрого чтения.
- В верхней части карточки добавлен компактный индикатор «Документы: N файлов»; по нажатию карточка прокручивается к документам и раскрывает их.
- Убраны emoji-значки из раздела документов для стабильного отображения в Windows.
- Таблица «ТРЕБУЕТ ВНИМАНИЯ» упрощена до колонок «Событие / Заказчик / Товар или объект / № контракта / Срок / Действие».
- Дата и срочность объединены в одной колонке «Срок», отдельные «Приоритет» и «Дней» убраны.
- На складе во вкладке «Остатки» добавлена явная кнопка «Движение товара»; двойной щелчок также сохранён.
- Переход из складского предупреждения теперь открывает именно внутреннюю вкладку «Остатки».
- Добавлены автоматические регрессионные проверки всех этих UX-изменений.

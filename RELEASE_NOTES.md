# v2.23.9

Безопасное обновление по воздуху через GitHub Releases.

- Включена проверка новых версий при запуске приложения.
- В «Настройки → Обновления» добавлена кнопка «Проверить сейчас».
- Можно отключить или включить автоматическую проверку при запуске.
- Обновлятор заменяет только UchetZakupok.exe.
- Рабочая база zakupki_work.db, документы и папка data обновлятором не заменяются.
- Перед установкой создаётся резервная копия текущей рабочей базы и документов.
- Новый EXE обязательно проверяется по SHA256 из GitHub Release.
- Старый EXE сохраняется отдельно перед заменой.
- После запуска новой версии updater ждёт 5 секунд; если новая версия сразу завершилась, выполняется автоматический откат на предыдущий EXE.
- Сохранены все исправления v2.23.8: ввод прочего расхода только суммой, пересчёт чистой прибыли, KPI по выбранному месяцу, нормализация товаров склада, дата оплаты и безопасное складское списание.
- Полный регрессионный прогон 2.17.2–2.23.9 и Windows smoke-test пройдены.

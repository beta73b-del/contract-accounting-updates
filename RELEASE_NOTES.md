# v2.23.20 — Развернутый просмотр закупок конкурентов

- Во вкладке **«Анализ конкурентов»** появилась кнопка **«Развернуть таблицы»**. Рядом с названием каждой модели есть **«Развернуть таблицу»**.
- Открывается одно максимизированное окно с двумя товарными вкладками — **Рутокен Lite 1010** и **Рутокен ЭЦП 3.0 3120**. Выбранная модель занимает почти всю высоту монитора, что позволяет видеть значительно больше строк.
- **F11** включает/выключает настоящий полноэкранный режим, **Esc** выходит из полного экрана либо закрывает расширенный просмотр.
- В расширенном просмотре доступны добавление, редактирование, удаление, открытие отдельной закупки и анализ модели. Основная и расширенная таблицы синхронно обновляются после изменений.
- При редактировании сохраняется выделенная строка; после удаления выделение сбрасывается. При отсутствии выбора действие редактирования/удаления не затрагивает ранее выделенную запись в основном окне.
- Вертикальная и горизонтальная прокрутка сохранены: физически все строки длинных списков на одном экране не помещаются.
- **База данных, склад, финансы, вложения и обновления ЕИС не изменяются.** ЕИС остаётся отдельной разработкой.

**Проверка:** локально на Windows пройдено 31/31 регрессионных тестовых файлов, включая Tkinter-тест с 140 закупками. [Windows CI Python 3.11](https://github.com/beta73b-del/contract-accounting-updates/actions/runs/42106083362) завершился успешно: тесты, сборка PyInstaller, DLL, запуск EXE, OTA/откат.

Версия 2.17 — контроль исполнения, оплаты, закупки и склада.

- «Требует внимания» разделяет подписание, исполнение, закупку и ожидание оплаты.
- После статуса «Вручен» контракт больше не попадает в контроль срока исполнения.
- Удалён отдельный этап «Приемка Заказчиком»; цепочка исполнения: «В процессе → Отправлено → Вручен → Исполнено».
- Срок оплаты — единый конечный срок, уже включающий приемку; контроль оплаты начинается после вручения.
- Складское списание фиксируется один раз при переходе в «Отправлено» и не повторяется при дальнейшей смене статусов.
- Для каждой товарной позиции добавлены варианты обеспечения: «Со склада», «Требуется закупка», «Отложенная закупка».
- Поддержано частичное обеспечение: часть количества может быть зарезервирована со склада, остаток учитывается как будущая потребность.
- Для отложенной закупки задаётся число дней до срока исполнения, когда позиция должна появиться в «Пора закупать».
- В складской сводке добавлена будущая потребность.
- Старые данные автоматически мигрируют без удаления пользовательской базы и документов.

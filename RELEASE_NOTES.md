# v2.23.18 — Ручное ведение истории цен конкурентов

- На вкладке «Анализ конкурентов» доступны **Добавить запись**, **Редактировать** и **Удалить**. Каждая закупка — самостоятельное наблюдение (цена за единицу, количество, ЭТП, дата, вид торгов, организация/ИНН), количества разных закупок не суммируются.
- Анализ по всем конкурентам выбранной модели запускается нажатием на **название модели в заголовке товарной таблицы**, без выбора строки. Двойной щелчок по отдельной закупке открывает её подробности.
- Убрана лишняя кнопка «Обновить таблицы»: после добавления/изменения/удаления данные обновляются автоматически.
- Исправлена компоновка пяти колонок и перенос пояснения при разной ширине окна. Обе модели остаются в отдельных регулируемых секциях.
- На Windows выполнена локальная проверка интерфейса при ширине 900/1180 пикселей, пройдены 31 из 31 регрессионных тестовых файлов. [Windows CI](https://github.com/beta73b-del/contract-accounting-updates/actions/runs/42084141469) прошёл сборку, запуск, тесты и OTA/откат.
- Исторические записи конкурентов в действующей локальной базе очищены отдельно по запросу пользователя (12 записей), с созданием проверенной резервной копии. **Обновление EXE ничего не удаляет из базы**.
- ЕИС автоматически не загружается; её интеграция — отдельная задача.

**Данные:** при обновлении EXE рабочая SQLite, контракты, склад, расходы и вложения не заменяются.

# v2.23.10

Исправление добавления прочих расходов.

- Окно «+ Прочий расход» переведено на стандартный диалог Tkinter.
- Пользователь вводит только сумму и подтверждает стандартной кнопкой OK.
- Enter также подтверждает ввод.
- Расход записывается в уже выделенный месяц.
- После сохранения сразу пересчитываются «Прочие расходы», «Все расходы» и «Чистая прибыль».
- Убрана зависимость от собственного Toplevel-окна, которое на некоторых Windows/DPI отображалось только одной строкой.
- Полный регресс 2.17.2–2.23.10, сборка Windows EXE и smoke-test пройдены.

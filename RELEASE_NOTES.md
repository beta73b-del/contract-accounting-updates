# v2.23.15

- Исправлен перезапуск после OTA: новый EXE и EXE при откате запускаются независимо от временной папки предыдущего процесса PyInstaller.
- Обновлятор удаляет унаследованные служебные переменные _PYI_* / _MEIPASS2 и устанавливает PYINSTALLER_RESET_ENVIRONMENT=1.
- Windows CI проверяет установку и откат с унаследованным onefile-окружением; проверяется появление главного окна приложения, а не только наличие процесса.
- Сохранено исправление v2.23.14: «Не хватает N шт.» при дефиците товара.
- База, документы и пользовательские данные при обновлении не заменяются.

Если обновление устанавливается из v2.23.14 или более ранней версии, старый обновлятор ещё не содержит исправления. Для первого перехода на v2.23.15 рекомендуется закрыть приложение и вручную заменить только UchetZakupok.exe, затем запустить его из Проводника.

# Локальная установка и резервирование ZIP

Отдельная утилита переноса без изменения `VERSION` или пересборки `UchetZakupok.exe`.
Исходный облачный каталог и действующая локальная SQLite сохраняются. Новый EXE и
`data/attachments` помещаются в `%LOCALAPPDATA%\\Programs\\UchetZakupok`.
Действующая SQLite остаётся в `%LOCALAPPDATA%\\UchetZakupok\\zakupki_work.db`.

## Запуск на Windows (Python 3.11+)

Сначала **закройте программу**. Нужны три файла из этого каталога:
`local_storage_setup.py`, `backup_service.py`, `app_launcher.pyw`.

```powershell
py -3 local_storage_setup.py --source-exe "ПУТЬ_К_СТАРОМУ_UchetZakupok.exe" --cloud-backups "ПУТЬ_К_ОБЛАЧНЫМ_АРХИВАМ" --dry-run
py -3 local_storage_setup.py --source-exe "ПУТЬ_К_СТАРОМУ_UchetZakupok.exe" --cloud-backups "ПУТЬ_К_ОБЛАЧНЫМ_АРХИВАМ" --install-task --shortcut
```

При установке обе версии БД и вложения сохраняются в отдельный аварийный ZIP, SQLite проверяется,
а EXE и местная копия БД сверяются по SHA-256. Старый каталог не удаляется. При повторном запуске
поверх существующей локальной установки операция прерывается.

После установки локальный `Run_Backup.cmd` использует SQLite Backup API и создаёт
проверенные ZIP с вложениями. Облачная копия сравнивается по SHA-256.
Файл с тем же именем, но другим хэшем не перезаписывается. Задание
`UchetZakupok_Backup` запускается каждые 4 часа через `cmd.exe`,
в том числе от аккумулятора, с попыткой запуска после пропущенного времени.
При недоступном облаке локальные архивы сохраняются и копируются позже.

## Ограничения

- Для переноса требуется закрытая программа и отсутствие незавершённого SQLite WAL/journal.
- Вложения, отсутствовавшие ещё до переноса, автоматически не восстанавливаются.
- Новая схема локальная и **не синхронизирует рабочую базу между несколькими ПК**.
- GUI, Windows Task Scheduler и обновление/откат тестируются отдельно; Linux unit-тесты их не заменяют.
- Версию приложения не изменять до отдельного релиза с проверками; исходные пользовательские базы
  и документы в GitHub не публиковать.

Результаты реальной установки и невыполненные проверки: issue #8 и `PROJECT_STATE.md`.

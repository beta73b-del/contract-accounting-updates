# Техническое задание — Windows/macOS + SQLite
Редакция 1.0, 25.11.2026. Полная версия документа: ТЗ_Контракты_ИП_Windows_macOS_SQLite.docx, создана в рабочем чате.

## 1. Цель
Автономная Web-версия «Контракты ИП» на Python/SQLite, одинаковая по функциям и расчётам на Windows и macOS. Эталон — действующая Web/Excel, а не отдельная Tkinter-версия. Рабочий сервер localhost:8765, книга Excel, вложения и настройки не меняются. Новая разработка изолирована на 8766. Не коммитить реальные базы или документы в GitHub.

## 2. Дублирование всех данных
Согласованный read-only снимок всех листов и журналов XLSX, всех карточек включая черновики/удалённые, исходных JSON notes/competitors/contract-folders/letter-drafts, всех связанных папок и документов. Для каждого файла — manifest, размеры, SHA256, исходный путь. В staging SQLite сначала сохранять полные raw-записи, затем нормализовать контракты, позиции, товарную историю и исправления, расходы, налоги, документы, письма. Номера — текст, деньги — копейки. Не выдумывать отсутствующие данные.

По каждой записи и периоду независимо сверить ID, revision, статусы/даты, все товары, сумму/себестоимость, физические остатки, резервы, стоимость отгрузок, расходы и чистую прибыль, налоги, связанные документы и хеши. Каждый результат PASS/FAIL/NOT_VERIFIED; любое необъяснённое расхождение запрещает переключение. Пока Excel рабочий — повторная проверка дельты перед запуском SQLite.

## 3. Windows и macOS
Windows EXE/MSI без отдельной установки Python/Excel; macOS .app и DMG для Apple Silicon и Intel, Finder/права/Unicode/Retina, при распространении подпись/notarization. Единая схема SQLite и логика, разные стандартные пользовательские каталоги. Реальные испытания на обеих ОС. До их проведения Mac не считать реализованной.

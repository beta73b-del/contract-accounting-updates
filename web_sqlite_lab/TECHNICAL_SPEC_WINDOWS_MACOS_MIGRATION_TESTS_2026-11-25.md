# Техническое задание — Windows/macOS + SQLite
Редакция 1.0, 25.11.2026. Полная версия документа: ТЗ_Контракты_ИП_Windows_macOS_SQLite.docx, создана в рабочем чате.

## 1. Цель
Автономная Web-версия «Контракты ИП» на Python/SQLite, одинаковая по функциям и расчётам на Windows и macOS. Эталон — действующая Web/Excel, а не отдельная Tkinter-версия. Рабочий сервер localhost:8765, книга Excel, вложения и настройки не меняются. Новая разработка изолирована на 8766. Не коммитить реальные базы или документы в GitHub.

## 2. Дублирование всех данных
Согласованный read-only снимок всех листов и журналов XLSX, всех карточек включая черновики/удалённые, исходных JSON notes/competitors/contract-folders/letter-drafts, всех связанных папок и документов. Для каждого файла — manifest, размеры, SHA256, исходный путь. В staging SQLite сначала сохранять полные raw-записи, затем нормализовать контракты, позиции, товарную историю и исправления, расходы, налоги, документы, письма. Номера — текст, деньги — копейки. Не выдумывать отсутствующие данные.

По каждой записи и периоду независимо сверить ID, revision, статусы/даты, все товары, сумму/себестоимость, физические остатки, резервы, стоимость отгрузок, расходы и чистую прибыль, налоги, связанные документы и хеши. Каждый результат PASS/FAIL/NOT_VERIFIED; любое необъяснённое расхождение запрещает переключение. Пока Excel рабочий — повторная проверка дельты перед запуском SQLite.

## 3. Windows и macOS
Windows EXE/MSI без отдельной установки Python/Excel; macOS .app и DMG для Apple Silicon и Intel, Finder/права/Unicode/Retina, при распространении подпись/notarization. Единая схема SQLite и логика, разные стандартные пользовательские каталоги. Реальные испытания на обеих ОС. До их проведения Mac не считать реализованной.

## 4. Перенос и восстановление на другом ПК
«Создать архив для переноса»: SQLite Online Backup, все документы/черновики/настройки без секретов, уникальный ZIP с manifest.json (schema version, IDs, относительные пути, размеры, SHA256, число объектов). Отсутствующий связанный файл блокирует статус COMPLETE. «Восстановить»: сначала dry-run без записи (защита от zip-slip/zip-bomb, симлинков, регистровых коллизий и несовместимой схемы), проверка SHA, integrity_check, foreign_key_check, всех бизнес-связей. До импорта сохранить резервную копию текущих данных; распаковать в staging, активировать только с подтверждением или выполнить rollback. Не затирать более новую базу автоматически, обе конфликтные копии сохранять. Повторный импорт не создаёт дублей. Испытать перенос Windows→Mac и Mac→Windows на чистых ПК, сбои питания и повреждение архива.

## 5. Полнота функций
Карточка контракта, создание/редактирование/черновик/закрытие, многопозиционность и даты, все действующие Web-статусы и сроки, полная оплата. Склад: фактический приход и исправление/удаление ошибочного прихода с пересчётом, физический остаток, резерв, доступный остаток, дефицит, однократная отгрузка, возвраты и себестоимость. Финансы: стоимость, выручка, комиссия, логистика, прочие расходы по месяцам, ручной налог, ставки УСН по годам, прибыль, рентабельность, KPI и корректное признание в периодах. Полный интерфейс: главная, реестр, доска, склад, аналитика, фильтры, календарь, профиль, настройки, корзина, документы, PDF, сопроводительные письма, акты и калькуляторы. Точное поведение и формулы действующей версии сохранять; не переносить правила из Tkinter без проверки исходника.

## 6. Автоматизированная приёмка
Сформировать BUTTON_MATRIX: каждый button/select/input/ссылка/контекстное меню, обработчик, состояния, API/БД-эффект, позитивные/негативные/граничные тесты, проверка сохранения после перезапуска; отсутствие инертных кнопок. Проверить все формулы независимым Decimal/SQL-оракулом и сверкой Excel↔SQLite по одинаковому снимку. Unit/API/SQLite, браузерный E2E (Windows Chrome/Firefox, macOS Safari/WebKit/Chrome), документы и PDF, Ctrl+C/V, DPI/Retina. Негативные: нулевые количества, пустые поля, неправильные даты, двойные клики, ревизии, BUSY, отключение питания, порча/потеря архивов и документов, конфликт облака, перезапуск, установка, обновление, откат. Все обязательные тесты PASS на реальных сборках обеих ОС; NOT_RUN не считать PASS. После полного автоматического PASS оставить пользователю только небольшой ручной визуальный чек-лист.

## 7. Этапы и критерии
R1 исходный консистентный snapshot и inventory; R2 staging и точная сверка; R3 полный backend/финансы/склад/документы; R4 весь действующий UI и BUTTON_MATRIX; R5 проверенный ZIP перенос/restore; R6 Windows EXE и macOS .app; R7 полный TEST_REPORT/PARITY_REPORT/RESTORE_REPORT. Публикацию и переход согласовать отдельно, VERSION не менять без релиза.

На 25.11.2026 первичная SQLite Lab проверена 20/20 Python + API и 10/10 Chrome E2E только на синтетике. Приватный снимок: 10 API-карточек, 11 ссылок на папки, 42 файлов документов и 11 JSON черновиков; одна папка не найдена, поэтому статус PARTIAL. Полная сверка Excel, готовая .app и все кнопочные испытания ещё не завершены.

# Contract Accounting Updates

Репозиторий обновлений приложения **«Учет заключенных контрактов»**.

## Как публиковать новую версию

Для каждого обновления создаётся GitHub Release с тегом вида:

`v2.16.1`, `v2.16.2`, `v2.17.0`

В Assets релиза должны быть два файла с точными именами:

- `UchetZakupok.exe`
- `UchetZakupok.exe.sha256`

Файл `.sha256` содержит SHA-256 контрольную сумму EXE.

Приложение автоматически проверяет последний GitHub Release при запуске. Если версия новее установленной, пользователю предлагается обновление. Перед установкой создаётся резервная копия данных.

## Важно

Папка данных пользователя, база контрактов, документы и вложения не входят в обновление и не должны размещаться в релизе.

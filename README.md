# Contract Accounting Updates

Репозиторий обновлений приложения **«Учет заключенных контрактов»**.

## Продолжение разработки

- [AGENTS.md](AGENTS.md) — правила разработки, бизнес-логика и защита пользовательских данных.
- [PROJECT_STATE.md](PROJECT_STATE.md) — текущая версия, результаты проверок, открытые вопросы и инструкции для ChatGPT Project.
- [CHANGELOG.md](CHANGELOG.md) — история опубликованных релизов и последующих изменений.

Перед новой задачей прочитайте эти файлы и сверяйте их с актуальным кодом и версией. После завершения обновляйте состояние проекта; после выпуска — историю версий.

## Автоматическая публикация

Релизы собираются автоматически через **GitHub Actions**.

Процесс:

1. исходники приложения обновляются в папке `app/`;
2. номер версии в `app/app_version.py` должен совпадать с файлом `VERSION`;
3. изменение `VERSION` запускает Windows-сборку;
4. GitHub Actions собирает `UchetZakupok.exe`;
5. рассчитывается SHA-256;
6. автоматически создаётся GitHub Release с тегом `v<VERSION>`;
7. в Assets автоматически публикуются:
   - `UchetZakupok.exe`
   - `UchetZakupok.exe.sha256`

Ручная загрузка файлов в Release больше не требуется.

## Обновление приложения

Приложение проверяет последний GitHub Release:
- автоматически при запуске;
- вручную через **Настройки → Обновления → Проверить сейчас**.

Если доступна новая версия, приложение предлагает установить её. Перед заменой EXE создаётся резервная копия базы и документов, а пользовательские данные не входят в обновление и не заменяются.

## Важно

Папка данных пользователя, база контрактов, документы и вложения не публикуются в репозитории и не входят в релиз.

## Анализ конкурентов — версия v2.23.19

Во вкладке «Анализ конкурентов» расположены две таблицы: **Рутокен Lite 1010** и **Рутокен ЭЦП 3.0 3120**. Каждая отдельная закупка отображается самостоятельной строкой с ценой за единицу, ЭТП, датой торгов/закупки, количеством и видом торгов. Данные хранятся в `competitor_records`.

Доступны ручные команды **«Добавить запись»**, **«Редактировать»**, **«Удалить»**. Обновление таблиц после изменений происходит автоматически. Нажатие на кнопку с названием модели над таблицей показывает анализ всех конкурентов этой модели. Двойной щелчок по записи открывает сведения о конкретном конкуренте (наименование/ИНН) и позволяет перейти к истории его цен. В статистике цены разных моделей учитываются раздельно.

**v2.23.19** исправляет центрирование текста в обеих товарных таблицах и таблицах анализа: заголовки и значения выровнены одинаково. [Релиз v2.23.19](https://github.com/beta73b-del/contract-accounting-updates/releases/tag/v2.23.19) проверен Windows CI и установлен на локальном ПК с сохранением предыдущего EXE; рабочая SQLite сохранилась без изменений.

**Важно:** данные — сохранённые наблюдения, а не текущая выгрузка ЕИС и не все ставки участников. Разработка независимого выгрузчика ЕИС ведётся по [задаче #11](https://github.com/beta73b-del/contract-accounting-updates/issues/11), без интеграции в EXE до отдельного успешного тестирования.

### Развернутый просмотр списка закупок (исходный код, без отдельного релиза)

На вкладке «Анализ конкурентов» предусмотрена кнопка **«Развернуть таблицы»**, а рядом с названием каждой модели — **«Развернуть таблицу»**. Открывается отдельное максимизированное окно со вкладками «Рутокен Lite 1010» и «Рутокен ЭЦП 3.0 3120». Одна выбранная таблица занимает почти всю высоту экрана, поэтому одновременно видны существенно больше строк, чем в двух вертикальных секциях обычной вкладки. Для очень длинных списков вертикальная прокрутка сохраняется (физически все строки могут не помещаться на мониторе).

В увеличенном окне доступны добавление, редактирование, удаление, подробности и анализ выбранной модели. Двойной щелчок открывает сведения о конкуренте. **F11** переключает настоящий полноэкранный режим, **Esc** выходит из него или закрывает просмотр, стандартная кнопка закрытия окна также доступна. Данные используются из той же SQLite, отдельная копия не создаётся. Новые/изменённые/удалённые записи автоматически обновляются в обоих представлениях.
